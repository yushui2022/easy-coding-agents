# v0.8.2：长任务中读取规则的确认

StockFlow 构建暴露出一个低效路径：模型通过 `read` 完整读取 AGENTS.md 后，下一轮
写文件仍会被当作尚未看到规则而拒绝。批量生成的内容被重复返回规则阻断，自动压缩后也会复现。

修复：完整、未被输出上限截断的 AGENTS.md 读取，将当前读取字节的指纹放入待确认集合。
只有下一个模型响应开始后才将其提升为已读，沿用现有工具批次隔离。

- 同一响应中的 read + write 仍不能绕过规则先展示给模型的要求。
- 分页读取、输出截断不会确认整份规则。
- 后续规则内容变化时指纹不匹配，必须重新读取。
- 读取子目录规则不代表读取了父目录规则。
- 指纹与规则加载器保持通用换行一致，且基于本次读取的同一份字节，避免二次读取的竞争。

相关专项：12 passed；全量回归：166 passed, 1 skipped（237.86 秒）。测试不调用付费模型。
新版本没有修改默认上下文容量，也没有取消作用域规则检查。

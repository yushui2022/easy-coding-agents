## 结果解释与限制

pytest 收集范围固定为 `tests/`，排除 `output/` 中生成的任务测试。先前 v0.5.2 的全量统计包含试跑产物，因此不能直接用跨版本测试数量比较新增覆盖。

MCP 使用每次操作独立会话，未验证 OAuth、跨调用服务器状态或公网生产服务器。子任务顺序执行且共享文件，不是隔离的并行工作树。模型是否有效委派、复杂真实仓库任务成功率不由这些机制测试证明。

账本显示供应商已报告用量和按用户配置费率计算的部分金额；失败、中断、缺少缓存分类、缺价格或旧版本历史都可能使结果不完整。服务商账单、优惠、阶梯价格、税费与 MCP 外部服务费用尚未核对。

一次中间回归遇到 Windows WinError 10055（事件循环创建时系统 socket 资源不足），不是 API 响应错误；之后改为顺序运行验证。MCP HTTP 起初受环境代理影响，已对回环地址禁用代理并禁用 HTTP 重定向，修复后本地传输测试通过。未在 Linux 主机验证。

另一次测试按浮点时间戳排序选取最后请求时，因快速模拟请求时间戳相同而误判状态；已改成直接检查取消记录数量，最终全量回归通过。

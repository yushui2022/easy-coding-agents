# 0.27.1 新任务区域调整

本轮范围为新任务欢迎区与共用输入框。减少重复的项目标识和顶部空白，让任务输入成为主要入口；模型与模式组合显示，操作权限和发送按钮在右侧，任务验证与快捷键保持次级层次。三个快捷任务仍只填入草稿，不自动执行。

## 实现

- `desktop/src/renderer/index.tsx`：移除欢迎区的重复项目行，组合模型模式，按用途分组工具栏，明确任务验证入口。
- `desktop/src/renderer/style.css`：调整阅读宽度、标题、垂直间距与输入高度，使用已有主题令牌划分编辑区和工具栏；简化快捷任务和键盘提示。
- `desktop/tests/execution-ui.cjs`：复用隔离 Electron 流程，检查 DeepSeek 快速模式标签、快捷草稿与聚焦，并保存单栏、工作区展开、深浅主题、窄窗口截图。

没有新增依赖、远程字体、网络请求或执行逻辑。模型选择、审批档位、发送快捷键、验证配置及会话恢复沿用原实现。

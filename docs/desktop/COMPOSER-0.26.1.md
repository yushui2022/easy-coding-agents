# 0.26.1 输入区底栏

输入框下方改成单行辅助栏：左侧“验证”，右侧键帽形式的发送、换行提示。去掉重复的模型来源和审批文字；来源仍在模型选择器提示中，审批范围在审批选择器提示中。

验证入口只在有配置时显示检查数量，数量不代表检查通过。展开后按“完成任务后运行 → 检查失败时”的顺序设置命令和修复次数。原先的授权、检查、自动修复与草稿恢复行为保持不变。

沿用现有颜色和字体，不引入依赖。窄栏缩短快捷键提示，深浅主题共用语义颜色；键盘可以展开设置。

# ECA Desktop 0.22.1：输入与模型配置

## 使用变化

- 任务输入框按 Enter 发送，Shift+Enter 换行，Ctrl/Cmd+Enter 仍可发送。中文输入法选字、组合输入结束时的回车和按键自动重复不会提交任务。
- 未选择项目时，Enter 打开项目选择；选好项目后再确认发送。任务执行中、模型切换中或项目恢复未完成时，不提交新任务。
- 模型设置中选择服务商并输入密钥，停止输入约 900 ms 后自动请求可用模型列表，随后选择模型并保存。已保存的连接打开设置时也会自动获取列表；密钥输入框按 Enter 可立即请求。
- 列表获取只调用服务端模型元数据 API，不生成回答，不下载模型权重。连接测试仍是明确点击后发送的小请求。
- 列表失败时显示密钥、地址或服务错误，可点击刷新重试，也可以展开“手动填写模型 ID”。不会自动选中第一个模型或启动任务。
- 编辑地址或协议时清空尚未保存的密钥。换连接、修改凭据或关闭设置后，旧请求返回的列表会被忽略。
- 项目恢复期间显示等待状态并禁用发送，避免项目尚未就绪时提交失败。

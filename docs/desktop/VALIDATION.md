已安装程序通过 Playwright 驱动真实 Electron 窗口，并连接本机 HTTP 模型模拟服务。除原生目录选择和确认框响应外，不替换界面操作、Python 后端或工具执行。最后一轮发送 10 次本地请求，包括连接探针、工具调用、模拟 401 和挂起请求。

覆盖：

1. 在界面保存模型和密钥、连接测试；配置文件没有明文测试密钥。退出重启后的请求仍通过测试服务的凭据校验。
2. 打开带中文和空格的项目；授权后真实写入 `hello.txt`，再授权执行 PowerShell 检查，界面显示实际通过结果。
3. 授权期间重载页面，待处理授权恢复，没有新增模型请求。
4. 查看真实差异、标记审查；外部修改文件后撤销被拒绝，没有覆盖用户的新内容。
5. 关闭再打开，读取同一项目 `.eca` 中的原会话和审查状态。
6. 请求已到达模拟服务但永不返回时，停止可立即处理。
7. 模型 401 显示错误；拒绝文件操作后任务继续结束，不写入被拒绝的文件。
8. 运行中关闭窗口选择继续，原窗口和授权保留；选择停止退出时正常清理，重开后显示已停止，不重发模型请求。
9. 只终止该测试应用所属的后端进程，再打开项目，恢复为中断状态，不自动重放任务或工具；后端重启后仍能展示新的模型错误。

安装版测试将其子进程 PATH 限定为 Windows 系统工具，移除 Python、Node 和 Git 路径；项目验证仍成功。这证明本轮任务使用随附后端，但不等于干净机器验收。

Python 协议测试另覆盖：项目独占锁、重复任务提交、授权允许/拒绝、过期和重复回复、问题回答、待授权时取消、等待模型时清理、旧 CLI 会话中断修复，以及切换模型不改变当前执行模式/隔离设置。

- 从未来/历史桌面版本到本版的真实升级，以及大型仓库、长时间会话的桌面压力测试。
- 安装包中的各类外部 MCP 服务、语言服务器、Docker 和用户项目工具链组合；它们仍需用户安装和配置，不属于随附运行时承诺。

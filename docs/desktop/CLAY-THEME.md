- `Sidebar.tsx` 抽出真实项目与会话导航；继续使用原项目选择、会话恢复和运行中禁用逻辑。搜索切换项目后清空，支持新建、选中与空结果。

- 模型设置、验证设置、审批、主输入区与侧聊输入区采用同一套表面规则；长文本、代码和差异保持平底，纹理不动画，不添加滤镜或网络资源。

# ECA Desktop 0.21.1：输入与界面修复

记录日期：2026-10-19。本轮按用户提供的《从 Demo 到企业级质感：前端升级执行指南》调整现有桌面工作台。

## 改动

- 原来未选项目时禁用任务输入；现在可以先写任务。选择目录只打开项目，用户明确发送后才执行。
- 草稿在取消目录选择、发送失败和界面刷新后保留，成功提交后清除。草稿使用当前窗口的 sessionStorage，不承诺应用退出后的草稿恢复，不存储 API 密钥。
- 未打开项目时展示桌面已保存的模型，打开后展示当前项目实际模型与配置来源。
- 移除大面积营销欢迎页，缩小导航与标题，统一控件、间距、边界及深浅主题。对话和输入是主要操作区域。
- 无项目时隐藏空详情栏；有项目时可以收起，窄窗口通过原生模态对话框查看修改、进度和用量。
- 设置、文件差异和诊断使用原生 dialog，支持 Escape、焦点限制与返回原按钮。配置表单有明确标签和未保存提示。
- 初始窗口按屏幕工作区域限制大小，避免固定高度超出可用桌面；后端异常时清除失效的待授权界面。

主要文件：`desktop/src/renderer/index.tsx`、`style.css`、`Dialog.tsx`、`desktop/src/main/index.ts`。保持现有 Python 权限、运行时、撤销冲突保护和会话存储逻辑。

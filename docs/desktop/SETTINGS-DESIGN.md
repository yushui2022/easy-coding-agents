# 模型设置页 · Skill 约束试版

> 下文记录最初的设置页试改。后续用户要求将陶土风格扩展至卡片和表单，当前源码的材质变化见 [CLAY-THEME.md](CLAY-THEME.md)。

基于已推送的 `bcb8e84`（0.28.0），按用户要求尝试其他界面的设计约束。范围仅限「模型与设置」弹窗。欢迎页、生成插画、主输入区、主界面设计令牌和模型选择弹窗保持原样。

## Skill 来源与取舍

采用 [deepparser/skills — design-cursor](https://github.com/deepparser/skills/blob/7f1e1891c5eb8539adbcae684e8159a0d92d0513/design-cursor/SKILL.md)，同时读取该提交的 `preview-dark.html`。这是社区整理的设计指南，不是 Cursor 官方组件库。本次读取并应用约束，未全局安装 Skill，也未引入该仓库的运行脚本。

- 使用暖白 `#f2f1ed`、浅表面 `#f7f7f4`、暖黑文字 `#26251e`，8px 控件圆角与间距节奏，细暖色边框及大范围柔和弹窗阴影。
- 深色表面采用配套预览中的 `#1a1915`、`#1e1d17`、`#2a2922`。次要文字比参考的透明度更高，以保证小字号可读性。
- 字体使用该 Skill 提供的系统字体方案及项目现有中文、等宽字体；不下载品牌专有字体或外部网络字体。保留 ECA 强调色，未复制 Cursor 品牌标志。
- 所有新颜色限定在 `.model-settings` 内，避免试版改动影响已经认可的欢迎页和输入区。

## 实现

- 左侧连接目录展示名称、模型 ID 和默认／密钥状态。目录和右侧表单独立滚动。
- 右侧分为连接信息、模型与响应、使用方式。API 地址和模型 ID 使用等宽字体；删除操作与保存区分开，并保留明确确认。
- 底部固定测试、保存、处理结果和未保存状态，长表单滚动时仍可操作。
- 在窄布局中，连接目录变为横向列表；表单单列。窗口原有最小尺寸不变，560px 验证仅在测试所属隐藏窗口中临时放宽尺寸。
- 首次添加连接时，默认选项曾因两个不存在的 ID 相等而误勾选并禁用；现在只有真实的已保存默认连接才锁定此选项。
- 密钥、模型目录请求、草稿恢复、默认连接和当前项目切换沿用原有接口和权限逻辑。

相关源码：`desktop/src/renderer/ModelSettings.tsx`、`model-settings.css`；`Dialog.tsx` 只增加可选样式类。

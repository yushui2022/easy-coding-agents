# 0.27.0 桌面视觉统一

本轮只调整呈现层，目标是统一整个工作台的比例、密度与主题。模型、授权、执行、会话存储和工作区生命周期沿用原实现。

## 调整

- `desktop/src/renderer/tokens.css` 是共享视觉契约：界面字体、阅读字体、代码字体分别定义；语义颜色、选中状态、边框、阴影、控件与常用间距集中管理。深浅主题均成对定义文字和背景。没有下载字体或增加依赖。
- 左侧导航以浅底、选中行和统一行高区分项目与会话。主聊天保留更多空间，右侧默认从 44vw 改为 29vw（360–460px）；用户仍可拖动、展开和收起。
- 单独审查时隐藏冗余的工作区标签行；修改、验证、进度、用量改为紧凑分段导航。多个工作区标签仍完整显示。
- 用户消息用弱填充区分，助手正文与执行记录保持阅读边界；失败记录带浅色提示。工具行按聊天容器宽度响应，不再只依赖整个窗口宽度。
- 输入区统一圆角、内边距、选择器与发送按钮。保留验证展开、快捷键提示、模型来源及权限范围提示。
- `ui/EmptyState.tsx` 在文件修改、任务计划、侧边聊天、浏览器中复用；只负责视觉，不接管数据或操作。模型设置和其他对话框继续使用现有 Dialog。

## 验证方式

所有界面检查使用本项目自己启动的隐藏 Electron 实例和 G 盘隔离数据，未控制用户窗口、未使用真实密钥、没有付费模型调用。

- `npm run build`：TypeScript 与生产构建。
- `npm test`（desktop）：现有 14 项单元测试。
- `node tests/execution-ui.cjs`：真实 App 的长工具记录、折叠与展开、错误、刷新、字体、深浅主题、欢迎页、设置弹窗、侧聊空状态、窄窗口与键盘返回。
- `node tests/e2e.cjs`：本地 HTTP 模型驱动实际文件修改、授权、输入法、验证修复、取消、异常恢复；测量文字对比度。
- `node tests/workspace-e2e.cjs`：侧聊、原生浏览器区域与项目预览、真实 PTY、窄窗口及资源清理。

截图会等待字体和有限 CSS 过渡结束，避免将切换主题的中间帧当成最终外观。Chrome 字体诊断已确认中文正文使用 Microsoft YaHei，控件使用 Microsoft YaHei UI。

# 陶土界面材质

使用内置 `image_gen` 生成的三张细颗粒陶土材质，用于真实 HTML 卡片、输入框和背景。没有生成文字或将交互控件画进图片。

| 材质 | 文件 | 用途 |
|---|---|---|
| 暖白陶粉 | [clay-chalk.png](clay-chalk.png) | 浅色侧栏、卡片和表单 |
| 深色炭陶 | [clay-charcoal.png](clay-charcoal.png) | 深色表面，配合更强的遮色层减少噪点 |
| 暖陶粉 | [clay-rose.png](clay-rose.png) | 浅色选中项 |

均为原生 1254 × 1254 RGB PNG，完整提示词见 [prompts.json](prompts.json)，大小和摘要见 [manifest.json](manifest.json)。没有后期改色、抠图或放大；实际显示的强弱由 CSS 中的纯色遮层控制。

`clay-surfaces.css` 定义共享材质变量。背景图静态重复，卡片边缘与输入框凹槽由轻微内外阴影实现。没有动画纹理、全屏滤镜或运行时图像请求；esbuild 将图片复制到本地构建目录并生成带哈希的 URL。图片合计约 8.6 MiB，多个控件复用相同文件。代码、差异和长对话阅读区保留平整底色。

0.28.2 根据反馈调粗显示颗粒：侧栏纹理平铺尺寸为 1254px，卡片 1120px，选中项 980px，表单字段 900px；相对初版约放大 2.2～2.3 倍。原始图片未修改，也没有增加图片文件或改变遮色层强度。

0.28.3 继续将颗粒放大约 50%，对应尺寸为 1880、1680、1470、1350px；原始素材仍为相同文件。

深浅主题、卡片、表单和真实侧栏的截图位于仓库 `output/playwright/clay-design/`。安装状态见 `docs/desktop/CLAY-THEME.md`。

# ECA clay background candidates v2

These four local PNGs are coarse-grain, low-contrast background candidates generated for the ECA Desktop clay material system:

- `clay-oat-v2.png` — warm oat ceramic for light navigation and workspace surfaces.
- `clay-terracotta-v2.png` — warm terracotta for selected states and accents.
- `clay-charcoal-v2.png` — charcoal ceramic for dark mode.
- `clay-chalk-v2.png` — pale chalk ceramic for light forms and workspaces.

They are background materials, not logos or foreground UI illustrations. Keep the translucent CSS veil above the texture, use a large background size, and do not add filters or animation. The existing v1 files remain for regression screenshots and can be removed only after a deliberate visual comparison.

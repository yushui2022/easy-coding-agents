# Welcome illustration

`eca-code-loop.png` is an original greeting illustration generated with the built-in `image_gen` tool for the ECA Desktop welcome view. It supplements the existing ECA logo rather than replacing it. The UI remains real HTML/React controls.

- Actual output: 1254 × 1254, RGBA PNG, 1,398,050 bytes, alpha range 0–255.
- Display: 64 CSS pixels (48 in a short window), transparent on both themes, decorative with empty alt text.
- Build: copied locally to `dist/renderer/welcome-loop.png`; no remote image request, generated text or runtime image generation.

## Generation prompt

Use case: stylized-concept. Asset type: a single small transparent-background greeting illustration for ECA, an understated premium desktop coding assistant. Create one original sculptural folded ribbon object, suggesting two gently interlocking rounded code brackets as a single continuous, open, looped shape. Material is softly matte terracotta ceramic with subtle tactile grain, warm muted burnt orange, rounded precise edges. Modern industrial design, calm, approachable, sophisticated, not a toy robot. Near-frontal three-quarter view, soft natural studio light from upper left, soft self-shading and delicate edge highlights. Single centered object, square composition, subject occupies roughly 78% of image with generous clear padding. No floor or cast shadow, actual transparent background. No letters, readable text, wordmark, symbols printed on the surface, logos, other objects, gradients in a background, watermark, or UI. The object must remain legible as a quiet 64-pixel illustration above a greeting on either warm white or charcoal UI; silhouette strong and simple, avoid fine decorative detail.
